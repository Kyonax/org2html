* WHAT IS @kyonax/org2html?
A TypeScript engine that transforms Org-mode (=.org=) files into static HTML or Vue 3 single-file components. Sanitize-first by default, plugin-aware, framework-agnostic. Designed as the *engine layer* beneath the future =kyo-blog= site, which composes engine output inside a Vue 3 + Vite + SCSS 7-1 shell that mirrors the visual language of the sibling [[https://github.com/Kyonax/kyo-web-online][kyo-web-online]] project.

#+BEGIN_EXAMPLE
org2html/
  src/
    index.ts                     public library API (parse + renderToHtml + applyTemplate + org2html())
    types.ts                     public type system (OrgMetadata / RenderOptions / AstNode / OrgPlugin / ...)
    cli/                         commander surface
      index.ts                   build / watch / test / help
      commands/                  { build, watch, test }.ts
      vue-generator.ts           Vue 3 SFC emission helpers
    parser/                      lexer + parser + ast factories + metadata extraction
    renderer/                    html-renderer + template (mustache) + sanitizer (DOMPurify + jsdom)
    plugins/                     code-highlight (Shiki) + toc
  templates/                     ships in npm tarball
    default.html                 full SEO surface (OG + Twitter + JSON-LD slot + manifest + RSS)
    styles.css                   engine-default CSS (consumer overrides via --template-dir)
    manifest.json / favicon.svg / robots.txt
  scripts/                       _lib.mjs + precheck.mjs + check-license-headers.mjs
  .github/                       CODEOWNERS + SECURITY.org + PULL_REQUEST_TEMPLATE.md + workflows/
#+END_EXAMPLE

* PREREQUISITES

** Required
- *Node.js* =>= 18.0.0=, enforced by the =engines.node= field in =package.json=. Verified on Node =20.x=.
- *npm* =>= 9.x= (bundled with Node 18+).
- *Git* =>= 2.30= for cloning and CI hooks.

** Optional
- *sharp* =^0.33= is an =optionalDependencies= entry. With it installed, the asset pipeline can probe image dimensions / convert formats. Without it, image-metadata features degrade gracefully.

** Shipped with =npm install=
- =commander ^11= (CLI surface), =chokidar ^3= (watch mode), =fast-glob ^3= (input discovery), =chalk ^5= (CLI output).
- =shiki ^0.14= (code highlighting), =dompurify ^3= + =jsdom ^23= (server-side sanitization), =probe-image-size ^7= (asset metadata), =slugify ^1= (URL slugs).
- =tsup ^8= (bundler), =typescript ^5= + =typescript-eslint ^8= + =eslint ^9= (lint + types), =vitest ^4= (tests).

* SETUP

#+BEGIN_SRC sh

#+END_SRC

* CLI SURFACE

| Command                                    | What it does                                                              |
|--------------------------------------------+---------------------------------------------------------------------------|
| =org2html build <input> [options]=         | Build Org files to static HTML. Default output dir =dist=.                |
| =org2html watch <input> [options]=         | Chokidar-driven dev loop; rebuilds on every change.                        |
| =org2html test <file>=                     | Single-file parser + render preview.                                       |
| =org2html help [command]=                  | Top-level or per-command help.                                             |

** Build / watch options
| Flag                          | Effect                                                          |
|-------------------------------+-----------------------------------------------------------------|
| =-o, --output <dir>=          | Output directory (default =dist=).                              |
| =-t, --template <file>=       | Custom HTML template path.                                      |
| =--template-dir <dir>=        | Directory with =default.html=, =styles.css=, =manifest.json=, etc. |
| =--no-sanitize=               | Disable DOMPurify sanitization (build only).                    |
| =--no-highlight=              | Disable Shiki code highlighting (build only).                   |

* LIBRARY

#+BEGIN_SRC ts
import { org2html, parse, renderToHtml, applyTemplate } from '@kyonax/org2html'
import type {
  RenderOptions,
  RenderResult,
  OrgAst,
  OrgMetadata,
} from '@kyonax/org2html'

const result = await org2html(orgString, {
  sanitize: true,
  codeHighlight: true,
  fetchRemoteAssets: 'metadata',
})

// result: { html: string, metadata: OrgMetadata, assets?: AssetMetadata[] }
#+END_SRC

The three-step pipeline is exposed individually for finer control:

#+BEGIN_SRC ts
const ast = parse(orgString)
const { html, metadata } = await renderToHtml(ast, options)
const finalHtml = await applyTemplate(html, metadata, customTemplate, templateDir)
#+END_SRC

* DEV AND BUILD COMMANDS

| Command                          | What it does                                                              |
|----------------------------------+---------------------------------------------------------------------------|
| =npm run dev=                    | =tsup --watch=. Live rebuilds into =dist/= on every save.                |
| =npm run build=                  | =tsup= production build into =dist/=.                                    |
| =npm run lint=                   | ESLint flat config over the source tree.                                  |
| =npm test=                       | Vitest single-run. Currently no test files (=tests/= is the Phase 5 work). |
| =npm run test:coverage=          | Vitest with v8 coverage.                                                  |
| =node scripts/precheck.mjs=      | Composite local gate. Currently runs =check-license-headers=.             |

** Validation gates
Run on every PR via =.github/workflows/ci.yml=. Seven jobs:

1. *ESLint* :: =npm run lint=.
2. *Precheck* :: =node scripts/precheck.mjs= (composite local gate).
3. *Vitest* :: =npm test=. Tolerant of an empty =tests/= directory.
4. *Production build* :: =npm run build=. Uploads =dist/= as a 7-day artifact.
5. *Security Scan* :: inline grep for =eval=, =Function()=, =innerHTML=, =document.write=, string-arg timers, hardcoded secrets, insecure =http://= URLs.
6. *Protected Files* :: advisory PR comment on edits to legal / governance / supply-chain / CI / build / release files. Never blocks merge.
7. *Pre-Check Label* :: aggregator. Applies / removes the =Pre-Check Failed= label.

* DESIGN SYSTEM CONTRACT

org2html is the engine; the visual identity belongs downstream. The canonical look-and-feel contract lives in the sibling [[https://github.com/Kyonax/kyo-web-online][kyo-web-online]] project — 8-family OKLCH palette, 7 UI primitives (=UiCard=, =UiLink=, =UiButton=, =UiImage=, =UiIcon=, =UiSectionHeading=, =BrandIcon=), cyberpunk HUD ornaments (=.hud-deco=, =.element-flare=, =.state-grid=, =.icon-glyph=, =.ccs-glyph=, =.heart-glyph=), accessibility floor, and the image pipeline rules. When emitting Vue SFCs that consume those primitives, the engine's =src/cli/vue-generator.ts= helpers produce output that drops into a kyo-web-online-shaped Vite + vue-i18n shell.

* CONTRIBUTING

See [[file:CONTRIBUTING.org][CONTRIBUTING.org]] for the full guide: prerequisites, code conventions, branch workflow, CI pipeline, and PR process.

Quick summary:

- Code style follows [[https://github.com/ccs-devhub][CCS]] standards, enforced via [[file:eslint.config.mts][eslint.config.mts]].
- *No comments in TypeScript source* (per [[file:AGENTS.md][AGENTS.md]]) except the GPL preamble + filename block + JSDoc on exported helpers that documents non-obvious WHY.
- Vue 3 Composition API with =<script setup>= only (when emitting SFC output via =vue-generator.ts=).
- Every source file needs the GPL-3.0-only license header, verified by =scripts/check-license-headers.mjs=.
- All changes require review from =@Kyonax= ([[file:.github/CODEOWNERS][CODEOWNERS]]).
- Branch model: =master= ← =feat-*= / =fix-*=.
- All PRs must pass 7 CI checks before merge.
